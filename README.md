# MDE Static Website

Pure HTML, CSS and vanilla JavaScript. No backend or build step required.

## Run locally
Open `index.html` directly, or use any static server.

Example:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Replace before launch
- `hello@mde.example` with the real MDE contact email
- Add real article content/images
- Add favicon/logo assets
- Update metadata and social sharing tags
- Connect a custom domain and static host/CDN
